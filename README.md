An entry for make.fun's one-day world news image contest (news-image-20261117).

- `main.py` copies `entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`). Standard library only.
- `build.py` draws `entry.png` with Pillow: `pip install pillow && python build.py`.
- `stories.py` holds the 46 stories in four tiers, each marked confirmed or claim, with its source.
- `data/` holds Natural Earth country outlines (public domain), made by `prep_geo.py`.
- `fonts/` holds Merriweather and Archivo, both under the SIL Open Font License 1.1.

Every illustration is drawn by `build.py` from shapes; no photographs or third-party artwork.
